# Multi-user Expense Tracker

A CLI (Command-Line Interface) based Expense Tracker developed as part of a university Python programming course.

This application allows users to manage personal finances by recording income and expenses, setting a budget, viewing transaction history, and storing data persistently using JSON.

## 1. Features:

- Multiple user profiles
- Add and delete income/expense entries
- Budget management
- Search expenses by category
- Transaction history
- Expense statistics using NumPy
- Persistent JSON storage

## 2. Technologies:

- Python 3
- JSON
- NumPy

## 3. Installation:

pip install -r requirements.txt

## 4. Usage:

python main.py

## 5. Project Structure:

- main.py
- Instance_methods.py
- function.py
- validity.py
- file_handling.py
- requirements.txt
- info.json
